- нагадування почати зміну у вибраний час;
- нагадування завершити зміну після 8–12 годин;
- попередження про надто довгу незавершену зміну;
- дозвіл на сповіщення з налаштувань;
- виправлено зміщення нижньої панелі після клавіатури та системного вибору;
