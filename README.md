# Моя робота v15.5 Navigation Architecture Fix

- сторінка більше не прокручується цілком;
- лише основний контент усередині main має власний скрол;
- нижня навігація винесена за межі scroll-контейнера;
- панель фізично зафіксована до viewport;
- після select, date/time picker і клавіатури виконується примусове відновлення viewport;
- під час клавіатури навігація ховається, після закриття повертається до нижнього краю;
- нагадування, Multi Job і фільтри збережені.
