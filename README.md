# Моя робота v6 Alpha — модульна архітектура

## Структура
- `index.html` — лише каркас запуску.
- `styles.css` — весь дизайн.
- `src/app.js` — сценарії та події.
- `src/state.js` — поточний стан застосунку.
- `src/storage.js` — збереження та сумісність зі старими даними.
- `src/payroll.js` — усі розрахунки зарплати.
- `src/format.js` — формат дат, часу та грошей.
- `src/ui.js` — шаблони й компоненти інтерфейсу.

Старі записи з v5 зберігаються, бо використовуються ті самі ключі localStorage.
