# Моя робота

Мобільний трекер робочих змін для iPhone.

## Публікація через GitHub Pages

1. Створи публічний репозиторій.
2. Завантаж у корінь репозиторію всі файли з цього архіву.
3. Відкрий Settings → Pages.
4. У Source вибери Deploy from a branch.
5. Вибери branch `main` та папку `/ (root)`.
6. Натисни Save.
7. Відкрий адресу, яку покаже GitHub Pages.

## Встановлення на iPhone

1. Відкрий опубліковане посилання в Safari.
2. Натисни «Поділитися».
3. Обери «На початковий екран».
4. Увімкни «Відкрити як вебпрограму».
5. Натисни «Додати».

Дані зберігаються локально на iPhone. Періодично використовуй кнопку резервного копіювання.
