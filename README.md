# Моя робота v11.7 Calendar Stable

Build: 2026.08.03.8

## Календар виправлено
- індикатори створюються окремими `span`, а не універсальними елементами;
- кожна точка жорстко обмежена розміром 4×4 px;
- точки не можуть розтягуватися по висоті або ширині;
- одночасно показуються максимум три точки;
- легенду прибрано;
- рекорд позначається маленькою зіркою;
- сума не показується в клітинці;
- робочий день має лише дуже легкий зелений відтінок;
- функції Smart Calendar збережені.

Номер версії видно на екрані.
