# Моя робота v16.6 Optimization & Widget Foundation

## Оптимізація
- CSS очищено від накопичених коментарів і зайвих порожніх рядків;
- розмір styles.css: 71,963 → 70,169 байт;
- додано modulepreload для основних модулів;
- Service Worker переведено на network-first для сторінок і stale-while-revalidate для ресурсів;
- старі кеші автоматично видаляються;
- дизайн та функціональність v16.5 не змінювалися.

## Widget Foundation
- додано `src/widget-state.js`;
- стан майбутнього віджета зберігається в `localStorage` під ключем `moya_robota_widget_state_v1`;
- зберігаються профіль, активна робота, колір, ставка, валюта, статус зміни, час початку, тривалість і поточний заробіток;
- стан оновлюється після кожного збереження і кожні 15 секунд активної зміни;
- доступ для інтеграції: `window.MoyaRobotaWidget.current()`;
- схема описана у `widget-state-schema.json`.

Справжній iPhone-віджет все одно потребуватиме нативного застосунку та WidgetKit.
