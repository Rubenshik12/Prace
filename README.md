# Моя робота v4

Функції:
- світла, темна або системна тема;
- автоматичний і ручний час приходу;
- кнопка завершення зміни з поточним часом;
- активний таймер;
- редагування та видалення змін;
- окрема ставка для кожної зміни;
- календар відпрацьованих днів;
- статистика та графік;
- поділ виплат 1–15 і 16–кінець;
- CSV, PDF, резервна копія;
- нагадування про незавершену зміну, коли браузер дозволяє сповіщення.

Для оновлення через GitHub заміни файли у корені репозиторію:
index.html, sw.js, manifest.webmanifest, icon-192.png, icon-512.png.
