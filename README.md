# Моя робота v15.9 Navigation Cleanup

Знайдена причина:
- styles.css містив одночасно п’ять різних систем позиціонування нижньої навігації;
- старі правила не видалялися, а накопичувалися;
- через конфлікти height/inset/top/bottom контент обрізався та з’являлася порожня зона.

Виправлено:
- CSS навігації повністю перебудовано;
- збережено лише стабільний базовий дизайн і функціональні стилі;
- залишена одна система layout;
- visualViewport більше не керує висотою;
- shell займає весь простір над навігацією;
- прокручується тільки main;
- панель ховається лише під час клавіатури.
