# Моя робота v9 — завершений календар

## Календар
- перемикання місяців стрілками;
- вибір місяця й року;
- підсумок місяця: зміни, години, заробіток;
- заробіток безпосередньо в клітинці дня;
- позначки планів і нотаток;
- деталі конкретного дня;
- усі зміни й плани за день;
- додавання зміни або плану з вибраної дати;
- редагування та видалення зміни;
- нотатка для кожного дня.

## Стабільність
- єдина прокрутка для всіх вкладок;
- контент не перекривається нижньою панеллю;
- збільшений нижній відступ;
- оновлений кеш PWA;
- старі зміни, плани й налаштування сумісні.
