# Моя робота v11.2 Work Mode

Build: 2026.08.03.3

## Work Mode
- під час активної зміни показується швидке поле завдань;
- дата, час, категорія та пріоритет не запитуються;
- Enter або «+» додає завдання;
- поле очищується й залишається готовим до наступного запису;
- завдання можна відмічати й видаляти;
- завдання автоматично прив’язуються до активної зміни;
- після завершення зміни вони доступні в її деталях;
- звичайні особисті плани залишилися;
- номер версії видно на екрані.
