# Моя робота v16.0 App Shell Rebuild

Повністю перебудована оболонка:
- appFrame — єдиний контейнер на всю висоту документа;
- shell містить верх і прокручуваний main;
- нижня навігація є звичайним нижнім рядком grid;
- немає fixed/absolute для навігації;
- немає visualViewport, calc висоти чи ручного top/bottom;
- навігація не може відчепитися від екрана;
- main завжди займає весь вільний простір;
- під час клавіатури навігація тимчасово приховується.
