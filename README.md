# Моя робота v7 Beta

## Нове
- календар показує заробіток за кожен день;
- натискання на день відкриває його підсумок і зміни;
- плани мають пріоритети та фільтри;
- повернено повноцінні налаштування доплат;
- понаднормові, вихідні, свята, чайові та дві виплати можна вмикати окремо;
- до зміни можна додати примітку;
- усі старі дані сумісні.
